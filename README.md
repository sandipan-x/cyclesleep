# CycleSleep

Sleep cycle calculator: find the best bedtime or wake-up time from 90-minute sleep cycles, with adjustable doze-off time and nap planner. Free.

## Features
- 24-hour ring dial visualising your sleep window and cycle boundaries
- Adjustable fall-asleep latency (5–30 min) instead of a fixed 15-minute guess
- Age-based sleep-need guide plus a one-tap power-nap planner
